# CSV Median Calculator

[![C++23](https://img.shields.io/badge/C++-23-blue.svg)](https://en.cppreference.com/w/cpp/23)
[![CMake](https://img.shields.io/badge/CMake-3.23+-064F8C.svg)](https://cmake.org/)

Консольное C++23 приложение для инкрементального расчёта медианы и других статистических метрик из CSV-файлов с потоковыми данными биржевых торгов.

##  Описание

Приложение читает CSV-файлы с историей биржевых торгов, вычисляет медиану цен **инкрементально** (добавляя по одному значению) и сохраняет результаты в выходной файл. Медиана рассчитывается постепенно: при добавлении каждой новой цены пересчитывается медиана с учетом всех ранее прочитанных значений через эффективный **two-heap алгоритм** (O(log n) вставка, O(1) получение).

##  Основные возможности

###  Базовый функционал
-  Чтение множества CSV-файлов из указанной директории
-  Фильтрация файлов по маскам имён
-  Инкрементальный расчёт медианы (two-heap algorithm)
-  Запись результатов только при изменении медианы
-  Парсинг TOML конфигурации
-  Подробное многоуровневое логирование (spdlog)
-  Graceful обработка ошибок без аварийного завершения

##  Конфигурация

### Базовая конфигурация (config.toml)

```toml
[main]
# Обязательный параметр: путь к директории с входными CSV-файлами
input = './examples/input'

# Опциональный параметр: путь к директории для выходных файлов
# По умолчанию: './output'
output = './examples/output'

# Опциональный параметр: список масок для фильтрации файлов
# Пустой список [] означает обработку всех CSV файлов
filename_mask = ['level', 'trade']
```


### Полный пример конфигурации

```toml
[main]
input = './data/market'
output = './results'
filename_mask = ['trade']

[performance]
parallel = true
num_threads = 8

[metrics]
enabled = true
types = ['median', 'mean', 'p95', 'p99']

[streaming]
enabled = false  # Включать для очень больших файлов
buffer_size = 2097152  # 2MB
```

##  Формат данных

### Входные CSV-файлы

Разделитель полей: **точка с запятой (`;`)**

#### 1. Файлы уровня стакана (level.csv)

```csv
receive_ts;exchange_ts;price;quantity;side;rebuild
1716810808593627;1716810808574000;68480.00000000;10.10900000;bid;1
1716810808593627;1716810808574000;68479.90000000;0.00400000;bid;0
1716810808593627;1716810808574000;68480.20000000;4.52800000;ask;0
1716810808593627;1716810808574000;68480.40000000;0.10200000;ask;0
```

**Поля:**
- `receive_ts` - временная метка получения (микросекунды)
- `exchange_ts` - временная метка биржи (микросекунды)
- `price` - цена
- `quantity` - объём
- `side` - сторона (`bid`/`ask`)
- `rebuild` - флаг перестроения (0/1)

#### 2. Файлы сделок (trade.csv)

```csv
receive_ts;exchange_ts;price;quantity;side
1716810808663260;1716810808661000;68480.10000000;0.01100000;bid
1716810809314641;1716810809312000;68480.00000000;0.00200000;ask
1716810809719209;1716810809717000;68480.10000000;0.00500000;bid
1716810809719209;1716810809717000;68480.10000000;0.00200000;bid
1716810809719209;1716810809717000;68480.10000000;0.16900000;bid
```

**Поля:**
- `receive_ts` - временная метка получения (микросекунды)
- `exchange_ts` - временная метка биржи (микросекунды)
- `price` - цена сделки
- `quantity` - объём сделки
- `side` - сторона (`bid`/`ask`)

### Выходные файлы

#### median_result.csv (всегда создаётся)

```csv
receive_ts;price_median
1716810808663260;68480.10000000
1716810809314641;68480.05000000
1716810809719209;68480.10000000
```

**Важно**: Строка записывается **только при изменении** медианы.

##  Алгоритмы

### Инкрементальная медиана (Two-Heap Algorithm)

```
Структура данных:
- max_heap: хранит нижнюю половину (max элемент доступен)
- min_heap: хранит верхнюю половину (min элемент доступен)

Инвариант: |max_heap.size - min_heap.size| ≤ 1

Вставка: O(log n)
Получение медианы: O(1)
Память: O(n)

Пример:
Цены: [100, 102, 99, 101]

Шаг 1: price=100 → max_heap=[100], min_heap=[] → median=100.0
Шаг 2: price=102 → max_heap=[100], min_heap=[102] → median=101.0
Шаг 3: price=99  → max_heap=[100,99], min_heap=[102] → median=100.0
Шаг 4: price=101 → max_heap=[100,99], min_heap=[101,102] → median=100.5
```
